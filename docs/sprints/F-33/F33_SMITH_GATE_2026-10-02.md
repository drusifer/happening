# F-33 Smith Gate Review (combined stories + arch) — 2026-10-02

**Verdict: APPROVED with one required change (applied: AC-9).**

## What works
- Ties the swing to the existing final-seconds escalation instead of a new
  alert mode — consistent with the F-32 "nudge → escalate" ladder.
- Mouse-over cancel (AC-7) covers the whole window, not just the 55px band;
  users reaching for a card never chase a moving target.
- Meeting-start only (AC-1): the end-of-meeting countdown does not swing, which
  avoids yanking attention mid-meeting.
- Scale alignment trick keeps the 3× glyph on-screen at both edges (AC-2).

## Required change (blocking → resolved)
- **No user path to disable motion.** `enableAnimations` is a test-only widget
  parameter; nothing in `lib/` sets it. A fast full-width swing is a vestibular
  trigger. → Added **AC-9: honour OS reduce-motion** (`MediaQuery.disableAnimationsOf`).
